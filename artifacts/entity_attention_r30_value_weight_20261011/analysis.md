# 第29轮起点：value权重实验结论与归因限制

两条独立分支与原权重1对照均已完成。共同第29轮终点、原第25–30轮6000局窗口、同一AdamW起点及逐次采样序列；lr2e-5、B256，各1000步。原始数据和完整曲线见[结果表](results.md)、[summary.json](summary.json)。

各完整网络对P4做200pair S1024/N1搜索，权重1／0.25／0的得分分别为67.25%／70.00%／62.125%。同开局面板配对差：0.25−1为+2.75个百分点，95% CI[−2.75,+8.125]；0−1为−5.125，区间[−11.50,+1.25]；0−0.25为−7.875，区间[−13.625,−2.00]。这里比较的是各整网对同一P4的得分差，不是候选之间直接对战；限定固定DEV与单训练轨迹，未校正多重比较。

0.25有未确认的正面棋力信号；本面板支持0整网弱于0.25。降低value权重后，最新代和完整窗口留出KL都比权重1更高。最新代MSE反而以权重0最低，但它搜索得分最低，说明总体结果标签MSE不足以单独给这些模型的棋力排序。

**这些搜索结果同时改变了policy分支与value分支，不能据此断言取消value loss使policy变差。** encoder共享且继续接受policy梯度；权重0的critic还保留AdamW动量与参数衰减，参数实测有小幅变化。因此“直接部署权重0所得整网”的结论，与“固定value评估器后权重0的policy能否受益”必须区分。greedy得分为81.75%／83.25%／80.875%，相对权重1的差异均未确认。

固定value的补充实验见[原第30轮完整value＋三个policy对照](../entity_attention_r30_fixed_value_arena_20261011/README.md)：三个policy各保留自己的完整encoder与动作查询模块，value统一使用原第30轮自己的encoder＋head，重新对P4跑同一套新200pair开局。不能只把第30轮head接到另一个encoder上，否则仍混入特征适配差异。

两种降权分支所有训练步均触发全局梯度裁剪；原权重1、0.25、0的裁剪前梯度范数均值分别约5.894、2.983、2.636。干预同时改变联合梯度方向、裁剪比例及AdamW更新，不能解释为仅减少critic参数训练量。权重0也不等于冻结完整value函数。
