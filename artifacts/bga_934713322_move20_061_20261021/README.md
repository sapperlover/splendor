## 显示的胜率从哪里来

在线显示取value头输出V，计算`(clip(V,-1,1)+1)/2`，含义是平局折半的模型期望得分估计，未经概率校准，不是根搜索Q、访问占比或多次续局胜率。

- 本人行动时：使用本人的观察，直接读取V。
- 对手行动时：从当前登录者已知信息重建对手的观察，必要时采样其未知保留牌，再把对手V的均值取负转换为本人估计。双方掌握的保留牌身份可能不同，显示值会因视角／信息集切换产生额外跳变。
- 显示值的这一计算不使用搜索预算，改为S16384不会自动把它变成搜索胜率。

S16384下：

- native N1：两次拿蓝绿红，一次盲保留一级牌；买061名次为4／2／10。
- native N4：三次拿蓝绿红；买061名次为3／3／2。
- 随机节点：三次买061，平均访问占比54.26%；拿蓝绿红17.22%，保留061为15.85%。买061的Q估分比拿蓝绿红高约1.072个百分点、比保留061高约0.172个百分点，这些是搜索内部估值差，不是真实胜率差。

对这一个局面，增加模拟数没有单调强化买061，也没有让不同方法收敛到同一首选。特别是N1只在一个确定化世界中加深搜索，增加预算并不消除该世界的抽样偏差。这里支持的是“原推荐可复现但不稳健”，不证明哪种方法棋力更强，也不证明061的真实最优性。

完整表见[results.md](results.md)，逐种子选择、访问量与Q在`summary.json`和`search/*.json`。N4比较动作Q时，应先在每个世界计算Q再等权平均，不能把不同世界的访问加权Q直接当成等权期望；对应检查见`result_validation.json`。
