# 5000步起点→9轮自迭代：固定留出与9代KL矩阵（2026-10-09）

复评历史run `runs/entity_attention_hybrid_static_graph_seed1` 的θ5000起点和第1–9轮结束模型（5000→9500步），并纳入N1 fork至14500步的结果。KL使用训练时同一调用链：`offline_train.evaluate_validation` → `AlphazeroLearner.evaluate_samples`，定义为 `KL(target‖student)=(加权CE总和−加权目标熵总和)/policy权重总和`。本次统计修订复用已有结果，没有新增训练、搜索或对战。

早期阶段在未训练对局上存在累计拟合改善，但单轮更新仍不稳定。下文分别报告**相对θ5000**与**相对各代训练前模型**的变化；这两种基线不能混用，也不能据累计曲线确定500步优于100步。

g9尤其能说明基线差异：θ5000为0.59012，采集／训练前θ9000已是0.48243，本轮更新后θ9500为0.49223。相对θ5000的−0.09789由本代进入训练前的−0.10768与本轮+0.00980合成；g9标签由θ9000的prior/value引导搜索生成，不能把这全部差距算作g9训练收益，也不能由此分离教师质量与目标耦合的贡献。

14500步时九代均高于各自训练前，也均高于9500步；其中g6–g9仍低于θ5000，体现了基线不同。可以报告对这些存档目标的保持下降，但此时3000局活动窗口已不含原9代数据，本矩阵**没有证明模型越来越拟合当前窗口**，也未单独确定遗忘／漂移的原因。

每代2048子集与完整current留出不是同一个统计量。例如g8子集本轮Δ为+0.00260，完整current为−0.00143；小差值可能随样本改变符号。逐代完整current变化与本表精确值见[review_statistics.json](review_statistics.json)，不能用完整留出数值逐项替代子集数值。

## 6. 与M4小步结果、棋力的关系

原9轮每轮1000局／500步，在线窗口6000局，并逐渐减少旧10000局离线语料的配额；第7轮开始淘汰第一轮在线训练数据。这为旧目标KL回升提供了训练分布变化的背景，尚不足以确定因果机制。

后期M4分支每轮200局／100步、policy近4代约800局、平均搜索标签，使用分头裁剪与value对encoder detach。模型／教师阶段、数据规模、优化器历史和训练方式均不同。两者更新数／新局数比同为0.5；当前结果不能单独证明1000局更优、500步更优，或把差异归于某一个配置。

此前M4固定数据C分支延长到500步，训练KL平均下降约0.03055、完整最新代留出平均上升约0.00728；其问题也不能简化为100步不足。早期矩阵与这些结果共同支持“存在可学习阶段，但后期边际更新／泛化收益不稳定”，尚无证据断言网络没有泛化能力或架构本身必然学不动。详见[M4整合结论](../../docs/reports/entity_attention_m4_diagnostics_conclusions_zh-CN.md)。

棋力必须按阶段区分：原θ9500对θ5000的直接得分69.5%［60.0%,78.5%］，已有相对起点收益；后续N1第50轮相对原第9轮在共同PPO面板上的得分差−2.00pp［−11.75,+7.50］，未确认进一步收益或退化。二者都是已有DEV证据，不是独立FINAL验收，不能将旧目标KL上升换算成棋力下降。来源见[直接对战](../entity_attention_search_screen_20261005/README.md)、[共同PPO面板](../entity_attention_strong_anchor_20261006/README.md)。
