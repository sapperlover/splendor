## 这盘棋的主要特点

- **blue_walker 的蓝色折扣转绿色得分链更完整。** 最终折扣为白2、蓝5、绿3、红1、黑2；一级牌仅贡献1分，二级8分、三级7分。他第20、23回合买两张蓝牌共5分，后四回合连续购买：第26回合补黑色零分卡，第27回合买3分绿、第28回合买1分蓝、第29回合买4分绿，最后四手得8分。最后4分绿是`084`（费用蓝7），最终支付蓝1金1。
- **ZeroDimensional 的保留占用更多回合。** 他明留7次、盲留2次，共9次；blue_walker 明留6次、无盲留。对应双方买牌11比13张、拿筹码9比10手。Zero最终折扣为白2、蓝1、绿1、红3、黑4，得分为一级2、二级7、三级4。这里描述的是实际节奏差异，未证明具体某次保留必然劣于替代。
- **模型并没有一直误判胜方。** 搜索在第9—10回合附近已逐渐偏向blue_walker；blue第12回合行动前网络V为+0.409、平均模拟回传+0.684，第18回合为+0.457/+0.794，第20回合为+0.860/+0.895；Zero同期搜索回传相应转负。即使Zero第17回合先拿4分红牌，模型仍判断blue的整体发展更好。不能把这些数换算成精确真实胜率。

## 值得细看的分歧

1. **blue第10回合 / BGA21：保留黑色零分`002`。** 网络实际先验排第2，搜索排第3、份额3.49%；两者首选是白色5分`082`（白3黑7）。他第14回合才保留`082`，且终局没有买。不能据此认为保留必然无用，仍可能有阻挡或选择权价值。
2. **blue第12回合 / BGA26：买白色零分`017`，模型想保留2分红`067`。** 这是访问较充分的最大Q分歧：实际598次（14.60%），搜索首选Q高0.460。实际补到白2以后，他第15回合免费买下刚翻出的绿`029`，第17回合仍买到`067`。实际后续得利包含新翻牌，不能让模型提前知道这张牌，也不能直接把单根Q差解释成人类失误。
3. **blue第19回合 / BGA40：拿蓝绿红，搜索零访问。** Greedy给实际动作1.19%先验、排第6；搜索首选是买保留黑`002`，而他延至第26回合才买。该根平均模拟回传已达+0.835，双方路线都处于模型看好的局面；实际动作没有Q估计，无法用零访问证明损失。
4. **Zero第4回合 / BGA8：保留黑色零分`003`。** 先验0.483%、排第11，搜索仅4次、排第13；模型偏好拿白绿黑。这是早期非常强的偏好分歧，但样本访问太少，不把估计Q差作为确证。

总体上，模型能识别这盘棋的中后盘优势方向，搜索也提高了合计主行动首选吻合率（24/58→30/58）。不过两位高手仍有模型不认同的走法；当前单种子分析既不能用来断言人类走错，也不能反过来证明模型被高手“打脸”。本次没有做替代走法续弈、额外种子矩阵或正式棋力对战。
