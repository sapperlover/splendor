## 结果解释

0步表示**同一份新随机critic**，不是原16500／16600的已训练critic。相同head接收不同encoder特征，所以起始预测与MSE可以不同，不能把这一步的优劣视为表示能力排名。

50步时16600留出MSE高0.006735，配对区间[+0.003547,+0.009905]；继续训练到200／500步后，这个差距消失。500步16600训练MSE低0.000626（区间[-0.001187,-0.000044]），绝对差很小；留出差值仍跨0。近期4代的500步留出MSE为16500=0.830123、16600=0.830345；较早11代为0.779073／0.778915。逐代留出6/15个点估计16600较低、9/15较高，没有逐代等效性结论。最新B2为0.885597／0.887949，但仅12局留出，不据此裁定新数据表现。

结合[此前固定16550 encoder的50步critic-only回放](../entity_attention_critic_only_replay_20261008/README.md)，当前证据更符合“共享表征变化后，已有critic未及时适应”，尚不支持“16500→16600已经破坏了encoder的value可拟合性”。同一16600 encoder/policy配新head训练500步后，整体留出MSE为0.792415，低于既有正式16600的0.808967；这里复用前次原模型的全量统计，没有重新评测正式模型或棋力。该解释是单起点、单配对初始化／采样轨迹上的推断，跨初始化稳定性与搜索收益尚未验证。

**还没有测出真正的拟合上限。**200→500步，16500的训练／留出MSE再降0.004629／0.003778，16600再降0.004548／0.003778；当前节点仍有收益，未做收敛检验。每边500步共128000个抽样引用，实际覆盖92019个不同train位置（全部221955个train位置的约41.5%），采用近期／历史各半的加权采样口径。该预算既不是500遍数据，也没有证明critic已充分拟合。现有曲线未出现训练MSE继续下降而留出MSE上升的模式，但约0.79的剩余误差仍不能拆解成信息不足、标签噪声或head容量限制。

下一步若要定位正式value退化，优先从16600的原critic做冻结主干的补训，观察能否保留新policy并恢复value精度，再比较补训前后同一policy的搜索棋力；若要回答严格的表示拟合上限，则需延长固定encoder训练至明确平台并做配对初始化重复。本次只执行用户指定的两条500步轨迹。

后续已完成[原16600 critic适配](../entity_attention_critic_adaptation_strength_20261008/README.md)：保留原head与AdamW状态、固定policy/encoder，额外0/50/200/500步的完整留出MSE为0.808967／0.789053／0.787500／0.786814。收益主要在前50步；已准备独立HEAD及前中期／后期critic替换的搜索对战脚本，按用户指令尚未启动。
