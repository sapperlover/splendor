第1–9轮原来每轮训练500步，前六轮旧池/在线渐进混合，第七轮起仅在线；第10–43轮每轮训练1000步、lr2e-5、6000局在线窗口。这里的训练历史用于解释教师来源，**本次采样不再沿用6000局窗口或渐进混合**，改为固定全部43000局的Train局面均匀有放回抽样。

旧的29000局池仍可用，来自早期attention三轮3000局、原hybrid九轮9000局、S1024/N1五十轮10000局、split二十轮4000局、M4行为2400局、趋势分支400局、native探针200局。它与本次池没有重用对局种子，总共可定位72000局；详见[旧池来源](../entity_attention_recent_pool_20261009/README.md)。本次不混入旧池：43000局已足够，且来自P4之后同一主线，先检验这个固定池的效果，保留清晰的教师范围。旧池未被删除。

## 对战与判定

顺序为完整训练→5组greedy→4组S1024/N1 DEV→选一个节点→独立开局确认，阶段各自使用子进程，退出后释放训练缓存和GPU资源。双方始终使用完整网络；对手固定原第24轮。搜索预算1024/N1、无根噪声、互换先后手，和棋半分，10000次整pair bootstrap。

Greedy固定开局34500000起，200pair；搜索DEV固定开局34600000起，200pair。四个搜索节点共用DEV开局，便于比较轨迹，但最高DEV得分存在选择偏差。**只按四个已完成搜索面板的最高得分选点，并列取较早节点**，在接触确认结果前写入`selection.json`。不依据Train loss、最低KL或最后一步自动认定最强。

随后使用34700000起的另一批**500pair**直接对原第24轮确认；即使DEV最佳仍低于50%，也按相同流程完成确认。最终收益判断主要看确认面板得分及95% CI：下界高于50%才支持相对起点的棋力改善；跨50%为未确认。独立的是开局与搜索随机流，不是训练seed；结果仍限定本次模型、对手和S1024预算。

value长训过拟合是既有风险，因此保留早期节点、按阶段/代际看留出，并测完整网络的搜索棋力。不同教师代际的终局value目标来自不同自对弈策略，较低混合池MSE也不保证当前策略的搜索更强。本实验同时扩大池和累计训练量，没有同预算6000局对照，**不能单独识别池大小或训练步数的因果贡献**。
