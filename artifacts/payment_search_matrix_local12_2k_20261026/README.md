# 第12轮模型：2000个多支付局面的花金对照

六组正式搜索和两组greedy全部完成。每组2000个相同局面，共12000次根搜索、73728000次模拟。

模型为本分支第12轮final（`round-011/checkpoints/final.pt`，SHA256 `2a6304e3470cab3dad78ec0a2789ee892892e741f3731cafc2197cde9bd2d45d`）；从其生成的第13轮10000盘中，均匀无放回抽取2000/89027个多方案支付根，来自1793盘。开局132、中盘1621、后期247；支付后直接终局34个。没有按模型选择筛样。

“多花金”指超过同一局面的合法最低黄金数，不等于已证明的错误。SxNy表示每世界x次、y个世界：S256N4与S1024N1总预算均1024，S4096N4总预算16384。所有选择T=0；有噪声为25%根噪声、Dirichlet α=0.3，六组使用共同世界种子，三组有噪声搜索使用同一份逐根噪声。有噪声greedy是对完全相同的native加噪先验直接取首选，仍为零模拟。FP/PTP关闭。

“前三多金份额”是前三候选中的多金概率／访问量占全部候选的份额；“前三内占比”先在各根前三内归一化，再跨根等权平均。候选不足三个时全部计入；并列按未加噪网络先验、候选顺序裁决。

## 执行和复核

正式搜索从首次启动到完成的墙钟时间32.14分钟；分块工作时间合计52.52分钟（并发块时间重叠）；每组分块时间（秒）：`{"S256N4_noise0": 78.26, "S256N4_noise1": 52.7, "S1024N1_noise0": 59.03, "S1024N1_noise1": 59.72, "S4096N4_noise0": 1342.01, "S4096N4_noise1": 1559.56}`。先单进程完成低预算组和一部分高预算块，再从已完成的原子分块切换到两个独立worker；每块仍为同样64根，候选和种子不变，分块互不重叠。每worker capacity256、双slot、batch buckets64/128/256、candidate buckets16/32/48/64，CUDA FP32/native-cudagraph、Torch单线程；不是整盘对战的评测A入口。无compile失败、无eager回退、无超桶。详细设备、命令、吞吐和资源见runtime execution/live文件。

每个根的安全DecisionRequest由checked引擎从原始轨迹重放，逐字段对照归档特征；搜索不接收真实隐藏牌堆或未来结果。全部36000个世界预算行、根与逐世界访问量、共同世界种子、共同噪声、未加噪先验已校验。34个直接终局根×6组的每个已访问动作Q均等于相应终局回报；四世界访问数组在这些根逐世界相同。

局限：每根只有一组共同搜索种子和噪声，没有多种子稳定性实验；直接终局只有34根，罕见事件及小分组比例不宜外推。本实验衡量支付分布，未评估胜率，也未验证某个非最低花金动作的实际优劣。

## 文件、执行与统计复算

- `plan.json`：模型、配置、种子、源码与输入身份；`root_refs.jsonl`：固定抽样引用和分组。
- `parallel_execution.json`：双进程续跑的命令、代码SHA与不相交分块规则；原串行会话停在已保存块后，未保存块重新完整计算。
- `summary.json`：完整分组、配对差异、先验与搜索关系；`verification.json`和`raw_hashes.json`：核验与原件SHA。
- `smoke.json`：总预算32的工程验证，与正式结果分开。
- `runtime/payment_search_matrix_local12_2k_20261026/roots.jsonl`、`search/`：安全请求和逐根／逐世界原始结果；`root_metrics.csv`：八组逐根统计。重型原件受现有runtime忽略规则覆盖。
