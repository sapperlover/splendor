# 固定M4数据：历史采样与policy梯度诊断

2026-10-09，状态：`valid`，三起点A/B/C实验已完成，共4500个训练更新、36个诊断节点和9个独立单步更新方向诊断。原连续实验和搜索对战保持停止。此实验只判断固定监督目标的拟合、泛化和更新方向，不提供棋力结论。

## 固定条件

使用M4连续分支第4、8、12轮的训练前`initial.pt`，累计步数分别为16800、17200、17600。三组近期四代窗口分别为79–82、83–86、87–90，互不重叠；每代200局。完整继承模型、AdamW一二阶矩、步计数和Torch随机状态，学习率1e-4、weight decay1e-4、分组clip1、各路batch256、value对encoder的detach均保持原样。

| 分支 | Policy采样 | 节点 |
| --- | --- | --- |
| A | 原方案：近期四代全部训练位置均匀抽样 | 0、50、200、500步 |
| B | 128个最新代位置＋128个前三代位置，桶内均匀抽样 | 同上 |
| C | 256个最新代位置 | 同上 |

A的“均匀”是原生产实现的**位置均匀**，每代占比随训练位置数变化，不强制每代64个。B/C只改变policy抽样；value始终使用原3000局FIFO快照，近期128＋更旧128，三条分支逐步使用**同一份value批次账本**。数据和M4标签不再生成或迭代，原NPZ、标签、checkpoint、训练状态均只读。相同value批次不意味着各分支的value函数相同：policy更新encoder后，会改变critic的输入特征。

A前100步的policy/value批次已与正式训练二进制账本逐条核对一致；A@100另检查模型及AdamW每个张量能否精确复现原正式结果，不作为额外训练分支。B/C使用同一个独立policy种子，value仍来自A的原始流。每个起点只有一个批次种子，不能据此给出训练随机性的总体结论。

## 拟合与留出指标

每代固定无放回选取4096个训练位置，所有节点和分支共用；训练诊断bank不限制训练抽样范围，也不会进入留出集。报告最新代、近期四代合计，以及四代分别的policy CE、目标熵、KL、value MSE。KL以有效policy权重归一化；四代训练KL是固定bank的合计，不是完整约6万训练位置的精确均值。

留出使用各代原有整局train/validation切分，评估**完整留出**；三组最新代分别19、23、21局，四代合计81、87、78局。每局贡献及完整统计保存在runtime，支持按对局聚类复核。第0步的current/recent KL和value MSE与原`validation_before.json`核对。

## 梯度与实际AdamW更新

每个起点在训练集内分别抽取最新代和前三代的8组×1024个位置，使用相同冻结M4目标。计算有效policy权重归一化的原始CE梯度（等于KL梯度），记录聚合余弦及8组独立minibatch余弦。拆分：全部policy参数、encoder、policy head；policy head包括action encoder、query/memory norm、cross attention及actor，critic排除。

对A/B/C各自第一份真实policy/value批次，重新恢复相同起点和AdamW状态，调用生产`train_split_step`做一次更新。保存真实`Δθ=θ_after−θ_before`，其中包含继承矩、裁剪、AdamW预条件和weight decay；记录它与当前batch／最新代／前三代**负梯度**的余弦、`g·Δθ`及诊断bank的实际单步KL变化。正的`cos(Δθ,−g)`或负的`g·Δθ`表示一阶下降方向，但有限步长可能仍让实际KL升高；不能把梯度余弦直接当作训练收益。

向量和批次引用保存在runtime，数值汇总保存在`gradients_r004/r008/r012.json`。

## 执行与恢复

```bash
conda run --no-capture-output -n splendor env PYTHONPATH=src OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 \
  python -u artifacts/entity_attention_policy_history_20261009/run.py
```

依次运行第12、8、4轮，每轮先梯度诊断，再A→B→C。每个任务使用独立子进程；2GiB原始数据LRU、有限标签缓存，无硬RAM上限或磁盘门槛。每25步保存模型、AdamW、Torch RNG和账本进度，中断后原命令恢复，最多重算尚未保存的24步。节点评测中断只重算该节点，已有checkpoint和完成节点保留。锁阻止同一入口同时写入。`--prepare-only`只冻结配置和核对原账本。

`specification.json`冻结输入路径、SHA、档案size/mtime、种子、批次计划和执行源码。较重的模型、账本、梯度向量及逐局指标在忽略的`runs/entity_attention_policy_history_20261009/`和`runtime/entity_attention_policy_history_20261009/`。本目录维护脚本、有限测试、每节点汇总、梯度汇总和`results.json`；未完成结果明确标注。

## 已测结果与结论

最新代留出KL如下；每组0步共用相同模型与固定目标。A/B/C为各自500步节点，数值越低越接近教师：

| 起点 | 0步 | A：原方案 | B：50%最新 | C：仅最新 |
| --- | ---: | ---: | ---: | ---: |
| 第4轮前／16800 | 0.26028 | 0.26924 | 0.25997 | 0.27176 |
| 第8轮前／17200 | 0.28908 | 0.28830 | 0.29583 | 0.29610 |
| 第12轮前／17600 | 0.30235 | 0.30765 | 0.29928 | 0.30569 |

C的固定最新代训练KL分别从0.26506→0.23710、0.28481→0.25646、0.28563→0.25029，但三个最新代留出KL均高于0步。三个起点平均训练KL下降0.03055，平均留出KL上升0.00728；按各起点整局配对bootstrap，留出变化95%区间[+0.00359,+0.01083]。前三代留出KL也全部上升：+0.00978、+0.00352、+0.00847。**只用最新数据可以改善训练拟合，却未改善未见局面，并牺牲旧代目标；去掉历史池没有解决泛化问题。**

B比A的500步最新代留出KL平均低0.00337，但区间[−0.00692,+0.00010]跨0；第8轮起点B反而更差，尚无跨起点稳定优势。C比A的500步四代合计留出KL平均高0.00691，区间[+0.00457,+0.00923]。这些区间只反映固定模型与已有留出对局的波动，三个起点来自同一训练轨迹，不是三个独立训练seed；多分支、多节点属于探索比较，不能据此确定最优配额或换算棋力。

梯度和原方案AdamW方向如下。最后一列正值表示A的实际第一步与最新代负梯度同向：

| 起点 | 全部policy梯度余弦 | Encoder余弦 | Policy head余弦 | A更新与最新代负梯度余弦 |
| --- | ---: | ---: | ---: | ---: |
| 第4轮前 | +0.877 | +0.927 | +0.812 | +0.074 |
| 第8轮前 | +0.321 | +0.788 | −0.052 | +0.204 |
| 第12轮前 | +0.060 | +0.488 | −0.113 | −0.079 |

**没有观察到三个起点普遍强烈的历史梯度冲突。** Encoder一直同向；第8/12轮policy head略有冲突，第12轮整体接近正交，而且8组minibatch余弦波动很大。第12轮提高最新配额能改变AdamW第一步对最新代的方向（A/B/C余弦−0.079／−0.008／+0.077），但并未因此获得稳定留出收益。多个单步的一阶预测为下降而实测KL仍上升，说明当前有限更新幅度的非线性效应也不能忽略；本实验没有分离AdamW继承矩、预条件及学习率各自的作用，不能直接归因为“Adam方向错误”。

对前述欠拟合／过拟合判断的修订：C提供了训练拟合下降、留出变差的直接证据，更支持有限数据过拟合和泛化不足；A的拟合进展较弱，容量、优化或标签噪声瓶颈仍未区分。局部代际冲突存在，但不能作为全部停滞的单一解释。当前不据此删除历史池、增加模型或修改正式配置。下一步值得在同一固定数据与账本上验证较小学习率能否让训练／留出同步下降；B保留为候选配额，尚未获胜。
