# R43：64根、两类动作的配对隐藏世界排序实验

沿用 [上一实验的64个局面](../entity_attention_r43_value_signal_64_20261014/root_bank.json)，不扩展根集合。原R43小模型SHA `b11f12c2ef1d48d86c8970eaae795f5139ae4c282476a52585a3fa5dff784f14`，没有训练。完整流程及参数已冻结在 [plan.json](plan.json)，根搜索与全部候选动作的Q／Value见 [search_roots.json](search_roots.json)。

已完成，后台链总用时305.08秒：50根补至128，合计6848份配对世界／13696条自然终局续局，全部回放、128条checked核验通过，无截断。60个不同动作比较中仍有40根未分辨，结果见 [results.md](results.md)。随后用户要求保持设计不变、仅改为双方S1024续局，独立分支见 [说明](../entity_attention_r43_action_ranking_64_s1024_20261015/README.md)；本目录原始数据与代码不被覆盖。

## 分组与动作

- 第一组32根：S1024访问首选A与访问次数最高的另一动作B。
- 第二组32根：S1024实际首选A与原Policy Greedy首选B。原64根的无噪声S1024共有28个首选冲突，按用户确认全部纳入；余4根为同选控制，id15、45、57、62，不计排序准确率、差值相关或错选损失。
- 两组互斥、合计64根。第一组来自剩余首选一致的根，两组局面分布不同，不能把组间表现差异全部归因于比较方法。第二组完整覆盖所有首选冲突；每根保留policy概率差、搜索访问份额差，可查看明显冲突的子集。

根搜索固定original R43、native S1024/N1、c_puct1.5、根噪声关闭、T0，seed38100000；只是选定待比较动作和读取预测，不用于后续续局。每边动作在同一份采样世界中强制执行，再由双方固定R43 Policy Greedy续到终局。每根先32份世界；不确定根补96份到128。同选控制留在32份。

## 配对与参考收益

每个根／world用独立派生种子从相同safe请求重建一个完整世界，两动作分支共享同一份对手暗牌、各tier完整牌序和初始状态digest。Greedy续局只接收当前行动方的编码特征，按合法候选顺序对logits取第一个argmax；没有额外搜索、根噪声或动作抽样。

参考收益为根玩家的终局z（胜1、和0、负−1）。估计动作差Δ＝mean(z_A−z_B)，以逐世界配对差统计，不用两个独立样本的误差。原有均匀隐藏世界采样器不是历史行为后验；参考值也只针对Greedy续局，不代表最优博弈价值。

Greedy实际推进使用既有native规则／特征实现，减少重复搜索的成本。工程总玩家回合上限400，未到自然终局时记录`engineering_truncation`和null z，不能算作和棋，不用其他策略替补。缺失配对扩大收益差区间到最坏情况范围；汇总明确列出，排序点指标排除这些根并标明有效数量。没有使用忽略回合特征的启发式循环判和。

根搜索在GPU完成。后续加载模型的GPU短验证遇到显存不足（已有外部服务占用），正式续局因此明确改为CPU FP32 eager、2线程、最多128个活动分支；不是运行时静默fallback。此前预检计划与运行源码保存在preflight/，失败记录保留在execution/，对应关系见preflight_migration.json。分组、动作、模型、种子、续局策略及统计规则不变；正式CPU配置以当前plan.json为准。

## 不确定与补样

对配对差d∈{−2,−1,0,1,2}的五类频率，使用预先固定的Dirichlet(0.5,…,0.5)先验，按根／样本量独立固定种子抽20000份后验。Δ的95%等尾后验区间包含0则从32补至128；128后仍跨0的根标记未分辨。不把全零观察差的零方差bootstrap误认为已证明平手。

这是明确带先验的Bayesian区间，不宣称频率学覆盖率。报告同时保留全部根的固定32份结果与自适应补样结果；自适应样本量、未分辨根、完整配对数、两边终局数全部输出。统计区间和错选损失也受64根、有限重复和采样器假设限制。

## 比较对象与指标

主比较：

1. `V_same_search_world`：S1024使用的那一份确定化世界中，执行动作后按相同规则折叠单候选强制选择，读取子节点Value。按子节点实际当前玩家转换到根玩家视角；终局直接用真实payoff。与native搜索一致裁剪到[−1,1]，未裁剪值另存。不能对支付／弃牌阶段一概取负号。
2. `root_Q`：现有native根边的value_sum／visits，已经采用根玩家视角。未访问动作Q为未定义，不伪造0。
3. `MCTS_visit_choice`：实际S1024访问首选A；排序及损失按这个实际选择统计，不用Q最大代替。

辅助比较：`V_mean_paired_worlds`在全部配对世界平均子节点Value；它和MC目标共享世界抽样，作为辅助去世界噪声诊断。`PolicyGreedy_when_in_pair`只在Greedy动作属于待比较两动作时统计。

输出经验排序准确率（观察平手／预测平手计半分）、已分辨根上的准确率、后验期望正确率、动作价值差相关性，以及错选造成的经验／后验期望收益损失。经验指标使用有限MC估计，不称为已知真实答案。z损失乘50得到续局得分率百分点，不是Elo。MCTS使用访问份额差的相关性，它是选择置信度代理，不是价值差。按独立根bootstrap10000次，给准确率、相关和经验损失区间。

Policy Greedy辅助列的差值是两动作之间的选择符号，也不是价值差；其排序与损失可比较，不能把这个相关系数解读为校准的价值预测能力。

根Q在搜索自身树内策略下估计，而参考终局来自Greedy；存在续局策略不一致。这个实验能定位排序错误及单世界敏感性，不能仅凭Q与参考值不同就证明搜索算法错误或value是唯一瓶颈。

  PYTHONPATH=src OMP_NUM_THREADS=2 MKL_NUM_THREADS=2 OPENBLAS_NUM_THREADS=1 \
  python -u artifacts/entity_attention_r43_action_ranking_64_20261015/chain.py
