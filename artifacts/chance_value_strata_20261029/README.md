# 下一张翻牌的value分层诊断

2026-10-29。结论：当前value对不同翻牌结果存在明显区分，公开补牌在前中期尤为普遍，盲留私人结果的差异更大；但不能概括为“绝大部分局面都有四个清晰档位”，后期公开补牌常较平坦。四层抽样有降低抽样方差的依据，不保证修复短战术或使排序符合真实棋力。

## 样本和评估时点

从在线第9轮模型采集的10000局中，固定seed20261029随机抽2000局，按实际发生的翻牌动作分层抽取1200个局面（来自922局）：公开补牌每期300个、盲留每期100个。前／中／后期按行动前双方最高公开分0—4、5—9、至少10分划分。

共枚举26192种下一张牌，使用第9轮和第12轮两个checkpoint对相同状态做52384次FP32 state-only value评估；单线程CPU，枚举和评估约37秒，抽样准备约13秒，没有进行新训练、搜索棋力赛或改动采集配置。输入身份、脚本SHA和预定义统计口径见[plan.json](plan.json)、[execution.json](execution.json)。

- 公开补牌：固定实盘购买／市场保留动作及本回合支付、退币、贵族选择，枚举对应牌堆所有可能顶牌，在结算后的下一个真实主行动决策点评估。若轮到对手，value转成原行动者视角。
- 盲留：对手看不见抽到的牌，直接评估对手将机械得到相同输入，因此固定一次实盘对手应手，等牌主自己的下一主行动点评估。为了隔离单次抽牌，排除了对手应手又触发翻牌的情况。它是这一条件子集，不代表所有盲留后完整不确定性。
- 其他暗牌固定为实盘身份，只交换待翻牌与当前牌顶；这诊断的是“条件于其余隐藏状态固定”的value分层，没有对其他暗牌信念做边际化。
- 每个局面至少4个可翻结果，均完整枚举。翻牌后没有下一非终局决策锚点的样本排除；纳入这些结局已定的末步补牌只会让后期结果更平坦。原抽样池公开事件早／中／晚28593／11136／6226个；盲留可用子集1296／876／518个。

百分比统一指`(clip(V,-1,1)+1)/2`得到的未校准估计得分率。跨度单位是百分点，不是实测胜率变化。先验阈值：“明显差异”取最大最小至少5个百分点，“四层清晰”取四分位组每对相邻均值至少差2个百分点；阈值是诊断定义，不是自然类别。

## 排序稳定性，以及四层是否降低抽样方差

用第12轮网络在相同有效决策点复评，第9轮与第12轮对候选翻牌的Spearman排序相关性中位数：

| 类型 | 前期 | 中期 | 后期 |
|---|---:|---:|---:|
| 公开补牌 | 0.968 | 0.975 | 0.956 |
| 盲留结果 | 0.975 | 0.983 | 0.983 |

同系列checkpoint可能共享误差；这证明排序跨相邻训练节点稳定，不证明排序正确或有棋力收益。

按第9轮value排序，用`array_split`分4个不重叠的、数量尽量接近的组，各组均匀抽1张，并按组内牌数／总牌数加权。对于“估计这批候选的value均值”，可直接从完整枚举计算抽样方差，无需随机重复：

`Var(IID4)=Var(Y)/4`；`Var(stratified4)=Σ_h P_h² Var(Y|h)`。

为了减少“用自身排序当然降低自身方差”的机械性，另以第9轮分层、估计第12轮value均值。相对普通4次独立抽牌，方差比中位数为：

| 类型 | 前期 | 中期 | 后期 |
|---|---:|---:|---:|
| 第9轮分层→第12轮value | **0.210** | **0.207** | **0.262** |
| 盲留对应结果 | **0.147** | **0.135** | **0.146** |

这些是即时网络value均值的抽样方差，不是MCTS最终收益／棋力的方差，也不包含先枚举打分的额外成本。若只用第9轮自身value评估，公开补牌方差比为0.170／0.171／0.198，盲留约0.122／0.125／0.122。无放回4抽的方差也在逐局面原件中保存，便于与最简单的去重复方法比较。

分层加权的依据可参考[Owen的方差缩减章节](https://artowen.su.domains/mc/Ch-var-basic.pdf)。当各层概率质量不同，不能每层都固定25%权重；完整搜索若采用该方法，需要相应处理世界／随机节点权重，当前独立世界平均策略并未因此自动修改。

## 两盘人机局面的直接复核

见[examples.json](examples.json)。

**第一次三级盲留：** 同一合法锚点下15种牌排序，前三名正好是077、076、078三张好白。四组大小4／4／4／3，最高组就是这三张牌，组均值约78.49%；其余三组均值约49.45%、52.91%、58.89%。如果四世界共用这套不重叠分层、各层抽1张，将保证至少采中一张好白，也不会再有3个世界都抽到076。最高组的概率质量是3/15=20%，不是25%；其他三组各4/15。

**最后一盘AI25保留046后的二级补牌：** 17种候选按下一行动者（人类）正常value转为AI视角评估，050仅排第8（64.09%），实盘068排第10（64.76%）；能否在两回合后完成050→055的精确战术，没有被即时value准确表示。四层分别5／4／4／4张，050处在第二层。该方法仍可能漏采050，更不能仅凭即时value分层保证AI阻挡077。

## 对方案的判断

1. **减少重复、覆盖好坏结果：有依据。** 共用同一候选池、同一套不重叠分层，各层抽1张可保证该次翻牌4张互异；简单无放回抽样本身也能避免重复，value分层额外保证沿估值排序覆盖不同区域。若每个世界各自重建池、各自分层，则不再保证跨世界不重复。
2. **普遍四层清晰：公开补牌不成立。** 前中期大多有估值差，但相邻四层都明显分开的只约三分之一，后期不到五分之一。仍可作方差缩减工具，不宜把四层当作四个真实胜负类别。
3. **保证不漏斩杀：不成立。** 即时value的错判可以非常稳定，跨checkpoint一致也无法兜底。短终局验证与分层采样针对不同问题。
4. **四层应在具体动作触发的随机节点定义。** 同一张牌在购买补牌、市场保留补牌、自己盲留中的影响不同；四个分层样本也没有覆盖整盘后续全部翻牌或所有对手暗牌。每次完整枚举约需剩余牌数次value评估，本次均值21.8张；实际GPU采集／搜索吞吐是否合算尚未测量。
