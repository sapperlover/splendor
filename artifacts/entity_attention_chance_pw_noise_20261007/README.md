# CPW k=0.25、α=0.5：A/B/C/D目标稳定性复测

2026-10-07。同一16500步冻结模型、200个原留出主行动请求、每组8次重复，完成6400次S1024搜索、6,553,600次simulation。与[旧确定化](../entity_attention_target_noise_20261007/README.md)及[不扩宽的随机节点](../entity_attention_chance_search_20261007/README.md)逐局面配对比较。原始指标代码未改。

**CPW保留了部分随机节点稳定性收益，但明显比不扩宽版本更抖：C组JS较旧确定化下降54.6%，D下降43.0%；相对不扩宽，C的JS变为4.95倍、D增加57.4%，D的Top-1一致率85.20%→76.43%。这与有限支持集带来的抽样敏感性相符，但不能单独证明训练平台期由标签噪声导致。**

新A/B固定的是整份抽样seed，仍每simulation重采暗牌。根噪声改变树路径也会改变抽牌事件序列，因此四组不是严格可加的方差分解。A逐项一致只证明可复现，不证明S预算充分。selection16700000、world16710000、noise16720000、bootstrap16730000，变化组按repeat加0–7。

CPW只限制未来物理抽牌结果；按决策边及真正剩余牌池上下文计算`max(1, ceil(0.25*N**0.5))`的支持集上限，不裁剪决策动作，也不对root暗牌信念扩宽。缓存卡牌ID、重新推进当前隐藏状态；复用阶段在已收入的不同卡牌ID间均匀抽样，是有限预算的分布近似。详见[方法与API](../../docs/guides/search_zh-CN.md#chance-progressive-widening可选)。

## KL及平均目标

以网络prior p、单次target π_i、8次经验平均π̄计算：`mean KL(π_i||p) = KL(π̄||p) + mean KL(π_i||π̄)`。最后一项为重复target分歧，不是全训练loss的噪声占比。每格仍为旧／不扩宽／CPW。
