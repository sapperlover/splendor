# 步数、有效学习率、value 与标签平均：200 局短训剂量对照

2026-10-23归档位置更新：本专题关联`runs/entity_attention_step_dose_20261007`中的4个抽样账本／逐步日志已按用户授权外置至[当日T7归档](../repository_archive_20261023/README.md)，原路径保留相对链接。复算这些原件前需解包；复训前将需写入的文件恢复为原位真实文件。历史指标、正式结果及来源身份不改写。

2026-10-07。四个轴都从同一 16500 步起点、同一 200 局 native 采集、同一条 batch 账本出发；各节点是同一条轨迹的前缀（25/50/100/200/300/500 步直接可比），单次标签臂与既有 native 检查点逐张量一致（100/300/500 步 max_abs_diff=0）。棋力面板为 50 pair（DEV 种子、对冻结起点、双方旧 native S1024/N1）；拟合参考为 200 个留出根上 8 次搜索的经验均值。

## 结论速览

1. **步数**：本批50-pair DEV中，50步点估计较高（avg4 56.5%、single 58.0%），100步为47%／45%。avg4 50−100为+9.5pp [−3.5,+22.0]，未确认差异；不能确定最优步数或100步必然过多。
2. **学习率**：同100步，lr2.5e-5拟合KL 0.2628对0.2665，棋力54%对47%，差+7pp [−5.5,+20.0]。较小lr是候选，未确认棋力更好；400小步虽拟合更好，棋力点估计45.5%，也未确定最佳lr×步数。
3. **value**：冻结critic与detach的policy轨迹相同，但完整value函数随共享trunk改变。棋力48%对47%，差+1pp [−12,+14]，未检出收益，不能断言critic漂移无影响或两种方案等效。
4. **标签**：50步avg4对single的差−1.5pp [−13.5,+9.5]，未检出差异；100步两名学生直接对打的60.5% [54.25,66.75]来自另一100-pair面板，支持这对模型的相对收益。不能由初筛确定平均标签的最优更新窗口或长期稳定性。

这些面板提供候选方向，不足以称200局／100步／lr1e-4为“最差区间”。后续M4已完成12轮，仍未确认稳定净收益；当前下一步见[M4整合报告](../../docs/reports/entity_attention_m4_diagnostics_conclusions_zh-CN.md)。原始数据和拟合／棋力表保留。

## 其他结论与边界

- 面板只有 50 pair，几乎所有配对差区间都跨 0；除方向性外不能单独作为确认。唯一较强的直接结论仍是上一实验的 100-pair 直接对打（avg4@100 对 single@100：60.5% [54.25%, 66.75%]）。
- 最好的单轮节点（single@50 58.0%、avg4@50 56.5%）也只是略高于 50%，且面板区间下沿贴 50；**仍然没有证明单轮更新净正，更没有证明自迭代启动**。
- 拟合与棋力在四个轴上都不一致：avg4 拟合最优在 100–200，棋力点估计最高在50；single 拟合最优在 25，棋力点估计最高在50；低学习率拟合更好，但 400 步并不比 100 步更强。不能再用 KL 单项来选步数。
- 步数和lr对照可以复用数据，较小更新值得验证，但最佳值仍未确定。此早期avg4标签由额外四次完整搜索组成，连同原行为约5倍模拟量；后续行为复用M4才是总4倍，两者不能混用成本。
- 边界：单起点、单采集/训练 seed、200 局、value detach、单一 fit bank；冻结 value 只冻结 critic head；没有多轮自迭代、没有多重比较校正、没有独立 FINAL。
