# 步数、有效学习率、value 与标签平均：200 局短训剂量对照

2026-10-07。四个轴都从同一 16500 步起点、同一 200 局 native 采集、同一条 batch 账本出发；各节点是同一条轨迹的前缀（25/50/100/200/300/500 步直接可比），单次标签臂与既有 native 检查点逐张量一致（100/300/500 步 max_abs_diff=0）。棋力面板为 50 pair（DEV 种子、对冻结起点、双方旧 native S1024/N1）；拟合参考为 200 个留出根上 8 次搜索的经验均值。

## 结论速览

1. **步数**：200 局下棋力峰值在 **50 步附近**，不在 100 步。avg4 50→56.5%、100→47.0%；single 50→58.0%、100→45.0%；200–500 步进一步走低。50−100 的配对差 +9.5pp [−3.5,+22.0]（avg4）、方向一致但不显著。
2. **有效学习率**：1e-4 对 200 局偏大。同为 100 步，lr2.5e-5 的拟合 0.2628 对 0.2665、棋力 54.0% 对 47.0%（+7.0pp [−5.5,+20.0]）；把同样的名义 lr×步数摊成 400 步@2.5e-5，拟合更好（0.2603）但棋力回落到 45.5%。**“100 步太多”里至少有一部分是“有效步长太大”，但更多小步并不等于更强。**
3. **value 分支**：冻结 critic head 与 detach 的 policy 轨迹逐点相同（fit 完全一致），棋力 48.0% 对 47.0%（+1.0pp [−12,+14]）。在这批数据、已经 detach 的设定下，critic head 漂移不是主要负项；此前 joint 500 的大退化来自 value 梯度进共享 trunk 的联合更新，本实验没有重新引入那条路径。冻结 head 也不是完整 value 冻结，trunk 仍随 policy 改变。
4. **标签平均 vs 单次**：50 步时两者无差异（single 58.0% 对 avg4 56.5%，−1.5pp [−13.5,+9.5]）；100 步时 vs 起点面板 47% 对 45%（+2pp [−12,+15.5]），但 100-pair 直接对打 avg4 为 60.5% [54.25,66.75]。拟合上 avg4 在所有 ≥50 步都优于 single，single 的最优点在 25 步、100 步已明显变差。平均把“可用步数窗口”推后，但单轮峰值没有超过单次@50；它的 4× 搜索成本更适合“要更多步数/多轮稳定”的场景，而不是单轮最优点。

综合：**当前正式日程 200 局 / 100 步 / lr1e-4 恰好落在本批数据的最差区间**（两种标签的棋力峰值都在 50 步，而 100 步已明显回落；1e-4 又是偏大的学习率）。先改步数/学习率是零额外搜索成本的旋钮；标签平均的定位是“允许更长/更稳的更新”，不是单轮棋力的必要来源。

## 其他结论与边界

- 面板只有 50 pair，几乎所有配对差区间都跨 0；除方向性外不能单独作为确认。唯一较强的直接结论仍是上一实验的 100-pair 直接对打（avg4@100 对 single@100：60.5% [54.25%, 66.75%]）。
- 最好的单轮节点（single@50 58.0%、avg4@50 56.5%）也只是略高于 50%，且面板区间下沿贴 50；**仍然没有证明单轮更新净正，更没有证明自迭代启动**。
- 拟合与棋力在四个轴上都不一致：avg4 拟合最优在 100–200，棋力最优在 50；single 拟合最优在 25，棋力最优在 50；低学习率拟合更好，但 400 步并不比 100 步更强。不能再用 KL 单项来选步数。
- 降低步数或学习率不增加任何搜索成本；标签平均要 ×4 搜索。当前证据下，先改日程（50 步或更小 LR）是更划算的第一步；平均标签更适合“需要长更新窗口/多轮稳定”的场景，是否值得 ×4 还要看多轮实验。
- 边界：单起点、单采集/训练 seed、200 局、value detach、单一 fit bank；冻结 value 只冻结 critic head；没有多轮自迭代、没有多重比较校正、没有独立 FINAL。
