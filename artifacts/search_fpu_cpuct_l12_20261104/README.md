# FPU／c_puct：L12 新搜索 vs L12 旧搜索（S128N1）

2026-11-04。目的：只换搜索、不训练，检验"未访问动作固定 Q=0"是否让搜索教师变弱。若 FPU 在同一模型上明显胜过历史搜索，再考虑接入采集；若不胜出，则否定"教师扭曲"假设。

## 代码改动

- `MCTSConfig.fpu_reduction: float | None = None`。`None` 保持历史行为（未访问边 Q=0）；设为 `r ≥ 0` 时，未访问边的 `sign*Q` 换成"节点行动者视角的父节点 Q − r"。
- 父节点 Q =（该节点展开时的网络 value ＋ 已访问子边按该节点视角的 W 之和）/（1 ＋ 已访问次数），不计未回传的虚拟访问。
- C++ `Node` 新增展开时的网络 value；根节点取根请求的网络 value。独立世界与随机节点搜索共用 `select()`，一处改动同时生效；Python 参照 `PUCTSearchPolicy._select` 同步实现。
- `FastSelfPlayConfig.to_dict()` 在 `fpu_reduction=None` 时省略该字段，旧采集配置与恢复身份不变；评测配置的 `search_config` 原样保存，旧配置无需改动。
- 说明同步到[搜索指南](../../docs/guides/search_zh-CN.md)。

## 验证

- [tests/test_search_fpu.py](../../tests/test_search_fpu.py)（12 项）：
  - 参数校验：负数、NaN、inf、bool、字符串报错。
  - 公式：手算的父 Q − r 加探索项与 `_select` 选点一致，含两种视角。
  - 一致性：伪随机 policy/value 下，native 与 Python 参照在 N1、N2、两个开局、`r ∈ {None, 0, 0.2}` 下根访问数和选点完全一致。
  - 随机节点搜索开启 FPU 后访问分布改变、预算守恒。
  - selfplay 配置在默认值下省略字段，可往返。
- 连同 native、MCTS、随机节点、批量搜索、selfplay、回放、组合模型等相关回归通过。
- 冒烟：r=0.2 两 pair 走完整配置A的 CUDA pool 路径，4 局全部有效，2 胜 2 负，异常、非法行动、工程截断、不变量失败均为 0；先后手交换、双方实际 S128N1 预算与 checkpoint SHA 核验通过，见 [smoke.json](smoke.json)。pool 为每方按各自 `search_config` 构建 `MCTSConfig`，FPU 由此进入 A 方（按代码路径确认，冒烟统计本身不区分搜索规则）。
- 机制检查见下节。

## 机制检查（不对战）

[mechanism.py](mechanism.py)：用 L12 greedy 自对弈 24 局（开局种子 47400000–47400023），每局每 3 个可搜索决策取 1 个，共 551 个真实根；分别用旧扩展默认配置、新扩展默认配置及 `r ∈ {0.1, 0.2, 0.3}` 跑 S128N1（总128，`c_puct`=1.5，无根噪声，T0，搜索种子 47410000）。按旧搜索根 Q 分箱，统计已访问动作数、目标熵、相对先验 KL。原始结果在 `runtime/search_fpu_cpuct_l12_20261104/`，汇总见 [mechanism.json](mechanism.json)。

**默认行为不变（事实）**：改动前扩展（SHA `cfebac5a…`）与新扩展（`134f06ef…`）在默认配置下 551/551 个根的访问数、value_sum、先验和选点逐位一致。

**阶跃基本消失（事实）**：已访问动作数（平均合法动作数）：

| 旧搜索根 Q | 根数 | 合法 | 旧搜索 | r=0.1 | r=0.2 | r=0.3 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| −1 ~ −0.6 | 100 | 13.9 | 13.87 | 12.32 | 11.08 | 9.84 |
| −0.6 ~ −0.3 | 55 | 17.3 | 17.35 | 10.85 | 9.04 | 7.60 |
| −0.3 ~ −0.1 | 60 | 19.0 | 18.45 | 8.85 | 7.45 | 6.52 |
| −0.1 ~ +0.1 | 108 | 20.8 | 11.49 | 8.10 | 6.80 | 5.98 |
| +0.1 ~ +0.3 | 74 | 19.5 | 6.05 | 7.04 | 5.77 | 5.04 |
| +0.3 ~ +0.6 | 66 | 18.1 | 4.18 | 6.61 | 5.50 | 4.68 |
| +0.6 ~ +1 | 88 | 19.6 | 2.68 | 5.70 | 4.81 | 4.23 |

- 旧搜索在落后局面几乎访问全部合法动作，领先局面只看 2.7–6 个；FPU 下两端收拢到约 4–12 个，落后局面不再把预算铺平，领先局面多试了一些先验外的动作。
- 目标熵同样拉平：旧搜索从 1.90（最落后箱）降到 0.54（最领先箱），r=0.2 为 1.74 到 0.73。
- 选点改变的根：r=0.1／0.2／0.3 分别 49／53／62 个（8.9%／9.6%／11.3%）。
- 根 Q 在领先箱略降（+0.85→+0.81），因为多试的动作拉低了均值；这不代表棋力变化。
- 机制检查只说明搜索分布按预期改变，不证明更强；棋力以对战为准。局面来自 greedy 自对弈，与采集分布不同。

## 对战（2a／2b）

[run.py](run.py)，启动器 [scripts/run_search_fpu_cpuct_l12_20261104.sh](../../scripts/run_search_fpu_cpuct_l12_20261104.sh)。

- 双方都是 L12（round-011 final，SHA `2a6304e3…`）。A 方用新搜索，B 方用历史搜索（未访问 Q=0、`c_puct`=1.5）。
- 双方 S128N1（每世界128×1世界＝总128），配置A：CUDA pool、12 search worker、1000活跃局、B500、local128、owner 双槽、B 桶[64,128,256,500]、C 桶[32,48,64]、等待5ms、shared slots2、FP32／native-cudagraph；无根噪声、T0、FP/PTP 关闭、12贵族。执行模板取自 [L12 嫁接面板](../graft_policy_value_l0_l12_20261104/configs/01_search_L12_vs_R37.json)，只换双方模型、搜索参数与种子。
- 每组 2000 pair／4000 局，同开局换先后手，各组共用开局。种子：开局 47420000–47421999，policy 种子基 47430000，搜索种子 47440000，bootstrap 47450000，组间差 47450001。
- 2a：`c_puct`=1.5，`r ∈ {0.1, 0.2, 0.3}`。
- 2b：取 2a 得分最高的 r（平分取较小 r），`c_puct ∈ {1.0, 2.5}`。2b 配置在 2a 全部完成后才冻结，记录于 `stage_b.json`。
- 2c（全新种子确认：S128N1 4000 pair、S256N4 2000 pair、S1024N1 500 pair）不在本脚本中。初筛按点估计选参，有选择偏差，进入训练前须经 2c 确认。
- 判定（2c）：S128N1 至少 +2pp 且区间下限大于 0，S256N4、S1024N1 不变差，才接入训练；否则否定"教师扭曲"假设。

执行源码：`prepare` 把当前工作树源码、带 FPU 的原生扩展、数据和本实验配置复制到 `runtime/search_fpu_cpuct_l12_20261104/source/`，身份与逐文件 SHA 写入 `source.json`，每次运行都复核。

```bash
bash scripts/run_search_fpu_cpuct_l12_20261104.sh prepare   # 冻结 2a 配置与源码，不对战
bash scripts/run_search_fpu_cpuct_l12_20261104.sh smoke     # r=0.2 两 pair 冒烟，仅写 runtime
bash scripts/run_search_fpu_cpuct_l12_20261104.sh run       # 2a 三组 → 冻结 2b → 2b 两组；中断后重跑同一命令续跑
bash scripts/run_search_fpu_cpuct_l12_20261104.sh status
```

结果写入 [results.md](results.md) 与 `summary.json`，每组结束自动更新。

状态：2a／2b 已完成（5 组共 10000 pair，单次会话 69 分钟），各组异常、非法行动、工程截断、不变量失败、策略循环判和均为 0。

**结果（事实）**：A 方（新搜索）对 L12 原搜索的得分：

| 组 | r | c_puct | 得分 | 95% 区间 |
| --- | ---: | ---: | ---: | --- |
| 2a | 0.1 | 1.5 | 54.763% | [53.288%, 56.225%] |
| 2a | 0.2 | 1.5 | 54.825% | [53.338%, 56.338%] |
| 2a | 0.3 | 1.5 | 55.350% | [53.812%, 56.863%] |
| 2b | 0.3 | 1.0 | 55.750% | [54.263%, 57.250%] |
| 2b | 0.3 | 2.5 | 51.625% | [50.138%, 53.075%] |

- r 在 0.1–0.3 之间差异不显著（两两配对差均跨 0），收益约 +4.8～+5.4pp。
- `c_puct` 1.0 与 1.5 无显著差（+0.40pp [−1.53, +2.30]）；2.5 显著更差（比 1.5 低 3.73pp [−5.69, −1.76]），抵消了大部分 FPU 收益。
- 按预定规则，2c 候选为 r=0.3、`c_puct`=1.0。它是 5 组中点估计最高者，存在赢家偏差；r=0.3 位于网格上沿，更大的 r 未测。

**推断**：修正未访问 Q 能在同一网络、同一预算下稳定多赢约 5pp；探索常数宜维持或调低，不宜调高。结论限定 L12、S128N1、自身原搜索为对手；更高预算、其他对手及作为训练教师的效果未验证。
