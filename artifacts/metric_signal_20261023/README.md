## 三次离线：早期进步很大，后期进入平台

| 实验 | 验证规模 | 起点 KL/MSE | 选中点 KL/MSE | 后期变化 |
|---|---:|---:|---:|---|
| 80k | 134,304 policy / 641,723 value | 0.55975 / 0.82151（step 13,528） | **0.42995 / 0.74904（94,695）** | 到135,279：KL 0.42722（更低），MSE 0.76089（更差） |
| 44k | 72,631 policy / 349,435 value | 0.45159 / 0.81805（7,432） | **0.22712 / 0.76801（59,453）** | 到81,748：KL 0.22431（更低），MSE 0.78668（更差） |
| 44k，lr2e-5 | 72,631 / 349,435 | 0.21893 / 0.76203（2,000） | **0.21721 / 0.75949（4,000，累计63,453）** | 到10,000：KL 0.21704，MSE 0.76371 |

- 80k 和44k从随机初始化开始的早期 KL 降幅约 **0.13 / 0.23**，MSE 降幅约 **0.073 / 0.050**；远大于后期波动，是**真实、可探测的拟合进步**。
- 80k 后期（94.7k→135.3k）KL 再降 0.0027，但 MSE 升 0.0119；44k 后期 KL 再降 0.0028，MSE 升 0.0187。KL 与 MSE 已经脱钩，按 KL+MSE 选点会被其中一项主导。
- lr2e-5 续训相对父59453：KL −0.0099、MSE −0.0085；这是同一验证集上相对较大的变化，但仍只有一组、一个seed，且是在5个点中选最低，不能当作已确认的配置收益。
- 80k 与44k的验证集规模/标签不同，不能直接用 0.43 vs 0.23 KL 判断哪个模型更好；只能各自看“相对自身起点”的拟合。

## 结论

1. **不是全是噪声。** 从随机初始化到训练中段，KL/MSE 有数量级上明显的真实下降。
2. **后期/在线/配置改动大多不可探测。** 大池六轮没有单调趋势；离线后期 KL 与 MSE 互相冲突；配置差异（数据池、lr）缺少同验证集、同seed的重复。
3. **最大方法问题是验证集不固定。** 大池每轮重抽 pooled validation，policy 有效位置仅约400，target entropy 也不同；跨轮 KL/MSE 不能直接当进步曲线。
4. 若要把“配置改动是否有效”变成可检验结论，至少需要：固定验证集与标签、按位置/对局配对 bootstrap、同时报告 KL 与 MSE、对选点做多重比较校正，并对配置做独立重复。
