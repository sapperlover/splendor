## 原件位置与恢复

本次清单中的原件全部保留在仓库相对路径，**本次没有把这些文件上传或迁移到T7**。现有其他归档的实际位置仍按各批次记录解释。运行输入如完整留出manifest、数据清单和root bank，在新机器上需要先恢复原件；本目录的投影摘要不能传给原始输入／恢复读取器。

历史原件还可以通过manifest的`previous_git_blob`和`head_before`定位；此前未跟踪的文件不能依靠正常Git历史恢复。取得原件后按manifest记录的SHA-256校验，再用于复算或恢复。正在运行的`offline5_vs_r37_10k_20261027/panels/`记录的是导出时快照，其文件可能由原进程继续更新；临时投影不代表最终完成结果，最终结论仍按该实验自己的summary和完整pair数解释。

停止跟踪不会清除已存在的历史对象，也不会清除本机`refs/codex/turn-diffs/...`快照。本次只减少后续版本化与分发的范围，不宣称已释放对应大小的本地磁盘空间；需要处理旧历史时另定范围。
