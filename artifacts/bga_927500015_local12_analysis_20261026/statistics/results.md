# BGA #927500015：全部搜索配置统计

本地第12轮原模型，8组×3种子×76个可选决策=1824次根搜索、15876096次模拟全部完成；CUDA无编译失败／fallback。主行动56步、可选支付20次，强制12次排除。仅一局，不是棋力面板。

“实际概率”：Policy为softmax概率，搜索为根访问份额，先等权平均3个种子、再等权平均局面。实际执行T0时仍是确定性首选。

“得分率变化”：相对各组3种子平均访问份额的首选，Δ=50×(Q实际−Q首选)，单位百分点；负数表示模型认为比其首选差。按同种子成对Q差求均值，再对可估局面等权平均。胜1／和0.5／负0；不是严格胜率，也不是独立续局验证的真实损失，不可逐步累加。

未访问Q保留缺失，不能补0。Greedy没有逐动作Q，不能给出同口径价值差。访问首选不保证Q最高，保留少数正向变化；主表不是对Q最大动作计算非负后悔值。

## 范围与解释

- 本表描述本地12轮模型在同一局面的搜索意见；与旧R20的逐配置比较另见comparison.md。
- Policy概率和搜索访问份额使用相同的实际行动，但二者不是同一概率模型；提高预算后的变化需逐组比较。
- Q差受模型value偏差和低访问影响，不能累加为整局损失，也不能据此给人类或模型定Elo。
- Chance标签中的N1表示单共享统计池，未知状态逐模拟重采；CPW限制逐步开放的随机结果支持。
